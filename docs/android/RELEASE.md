Android debut of **campus lookup**. Download `campus-lookup-1.0.0.apk` below and open it on Android 8 or newer. Android may ask you to allow installation from your browser or file manager.

- Keeps the charcoal palette, monospace typography, and light theme.
- Bottom navigation for materias, aulas libres, and room schedules.
- Larger touch controls, collapsible academic filters, quick durations, clear results, and one-tap room schedules.
- Direct access to public Austral Planning: no login, Python, desktop, or hosted backend required.
- Remembers searches, campus, theme, and the last search mode. Uses Argentina time.
- Clear loading and retry states; failed requests never produce stale availability results.

Requires internet and an up-to-date Android System WebView. Independent app, not an official Universidad Austral product. An aula marked free has no registered reservation; physical occupancy can differ.

Validation: release build, Android lint, four Java boundary tests, 17 shared engine tests, nine Python regression tests, and browser interaction/layout checks at 320–768 px. Live public Planning endpoints checked. No physical Android device or emulator was available for installation testing.

`SHA256SUMS` verifies the APK download. Release APK is signed with the dedicated campus lookup key.
